# 📊 HR Attendance & Leave Management Dashboard (Excel)

## Overview
This project provides a **strategic HR Attendance & Leave Management Dashboard** built in **Microsoft Excel**.  
It transforms raw employee data into **interactive dashboards** that help HR managers, department heads, and executives analyze **attendance trends, absenteeism rates, and leave distribution** in real-time.

📄 Detailed documentation is available in the [HR_Attendance_Dashboard.pdf](./HR_Attendance_Dashboard.pdf).

🔗 Direct Excel File: [Dashbord 2.0 Adv.xlsx](./Dashbord%202.0%20Adv.xlsx)

---

## ✨ Key Features
- **Executive Dashboard**
  - At-a-glance KPI Scorecards  
  - Monthly Attendance & Absenteeism Trends  
  - Leave Type Distribution (Casual, Privilege, Sick)  
  - Departmental Absenteeism Snapshot  

- **Department-Level Dashboard**
  - Interactive Slicers (Department, Manager, Head)  
  - Departmental KPI Scorecard  
  - Top & Bottom Performers (attendance-wise)  

- **Individual Employee Profile**
  - Employee Details Card  
  - Leave Utilization Gauge  
  - Leave Type Breakdown (Stacked Bar Chart)  
  - Attendance Calendar Heatmap  

---

## 🛠️ Tech Stack
- **Microsoft Excel** (Power Query, Power Pivot, PivotTables, DAX, Conditional Formatting)  
- **Data Sources**:
  - Employee Master Data (100 employees)  
  - Attendance Log Data (Jan–Sep 2025)  
  - Nomenclator (status code reference)
